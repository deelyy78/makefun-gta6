**Solano Heat** — an original open-world crime game that plays in a desktop browser from static files, no build step and no network. Work the docks of Port Solano as courier Dario Mercer: explore a sun-soaked art-deco city on foot and by car, steal and drive anything with wheels, run a six-job story arc for fixer Marisol Vega, dodge or outrun the Port Solano PD as your wanted stars climb, and pick up taxi fares, street races and hidden cash stashes on the side. Traffic and pedestrians live their own loops, police chase and bust, rivals shoot back, and your cash, respect and story progress save to the browser. Everything — city, names, story, art and the WebAudio-synthesised sound — is original to this entry and drawn by its own small 2.5D canvas engine, split across `game/src/` one job per file.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or serve game/ with any static file server
# hand-in check: mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
